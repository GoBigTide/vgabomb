# Night Artillery

A simple browser homage to classic DOS artillery games like **VGABomb** (1988).

- Two players, same keyboard (hotseat)
- Random hills every game
- Wind, angle, and power
- Destructible terrain
- 100% client-side — open `index.html` or host on GitHub Pages

## Controls

| Action | Keys |
|--------|------|
| Angle | A / D or ← → (Shift = bigger step) |
| Power | W / S or ↑ ↓ |
| Fire | Space or Enter |
| New game | Button (or Space after win) |

## Deploy

Upload this folder to GitHub Pages, Netlify, Cloudflare Pages, etc.
